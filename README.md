# Coupang 1P DOC Dashboard

쿠팡 파트너스(서플라이허브 › 애널리틱스 › 기본물류지표)에서 다운로드한 재고/입출고 파일을
브라우저에 업로드하면 그 자리에서 시각화해주는 1P 운영 대시보드입니다.
서버나 백엔드 없이 순수 클라이언트(정적 HTML)에서 동작하며, 업로드한 파일은
브라우저 밖으로 전송되지 않고 로컬에서만 파싱됩니다.

**바로가기(index.html):** https://kimco12.github.io/Coupang_1p_doc/

> 대시보드 안내문구에도 있듯, 발주 보고서 등 자동 산출된 수치는 담당자 검토 후 사용하세요.

## DOC 사용 방법
1. 서플라이허브 → 애널리틱스 → 기본물류지표에서 파일(.xlsx / .xls / .csv) 다운로드
2. 위 바로가기 접속 → 다운로드한 파일을 업로드 화면에 드래그하거나 "파일 선택"으로 업로드

## 입고 예정 체크 사용방법
1. 서플라이허브 → 물류 → 발주 SKU리스트 → 기간검색 (입고예정일로 체크) → 원하는 기간 필터 → 검색 → 상품목록 다운로드 → 전체로 다운로드하기
2. DOC 사용방법 이후 상단 "🚚 입고 예정 체크" 탭 클릭 → 다운로드한 파일을 업로드 화면에 드래그하거나 "파일 선택"으로 업로드
   (1차 DOC 데이터는 그대로 유지된 채, SKU ID 기준으로 자동 매칭됩니다)

## 주요 기능

### 📦 DOC 현황
- **필터**: 상품 카테고리 / 세부 카테고리 / 상태(품절 등) / 발주상태 / 급상승 여부로 데이터 좁혀보기
- **뷰 탭**: 전체 / 일평균 출고량 체크 — 이하·이상 조건과 숫자를 직접 입력해 원하는 출고량 구간의 SKU만 검색
- **KPI 클릭 필터**: 위험 SKU / 급상승 SKU 카드를 클릭하면 해당 SKU만 테이블에 필터링
- **📋 발주 보고서**: 업로드 데이터 기준으로 즉시발주·발주준비·출고급상승 항목을 자동 산출 + 클립보드 복사
- **📈 입출고 추이**: 행 클릭(Ctrl/Shift로 다중 선택)으로 선택 상품의 일자별 입출고·재고 흐름을 차트로 확인, 단일 SKU는 `[SKU ID] 상품명` 형태로 간결하게 표시
- **📊 입고·급상승 분석**: 즉시 입고 필요 / 입고 준비 필요 / 급상승 요인 카드 — SKU ID 복사와 `[SKU ID] 상품명` 복사 버튼 지원
- **⬇ 엑셀 다운로드 / 🖨 인쇄**: 현재 화면(필터·정렬 반영)을 엑셀로 저장하거나 인쇄
- **🚫 제외 SKU 관리**: 단종 등으로 더 이상 발주 검토가 필요 없는 SKU를 SKU ID/상품명 검색으로 찾아 클릭 한 번으로 제외 — DOC 현황·입고 예정 체크·모든 보고서·KPI에서 공통으로 빠지며, 브라우저에 저장되어 파일을 새로 올려도 유지됨
- **SKU명 열 너비 조절**: 상품명이 길 때 슬라이더로 열 너비를 짧게/길게 조절(두 탭 공통 적용, 설정 저장)

### 🚚 입고 예정 체크 (발주 PO 2차 데이터)
- 1차 DOC 데이터(현재재고·일평균출고)와 SKU ID로 자동 매칭해 "입고 예정 물량으로 대응이 되는지"를 계산
- **KPI**: 발주 등록 SKU / 확정 대기 SKU(발주는 있으나 미확정, 클릭 필터) / 추가발주 필요(확정수량 반영해도 부족, 클릭 필터) / 입고 지연 SKU(확정됐지만 예정일 경과·미입고, 클릭 필터) / PO 미등록 위험 SKU(위험·품절인데 발주가 없음, 클릭 시 목록)
- **입고 후 대응 계산**: 확정수량 중 이미 입고 완료된 물량은 현재재고에 이미 반영돼 있으므로 제외하고, **미입고 확정수량만** 입고예정일에 반영해 재고 시뮬레이션 → 반영 후 DOC(일)와 품절 예상일을 계산 (재고는 0 밑으로 내려가지 않도록 현실적으로 계산)
- **예정일 경과 + 끝내 미확정인 발주는 자동 제외**: 무산된 발주가 계속 알람에 남지 않도록 집계에서 자동으로 빠지며, 제외 건수는 안내 문구로 표시
- **📋 발주 요청 보고서**: 확정 요청 필요 / 추가 발주 필요 / 발주 미등록 위험을 `DOC · 품절예상일 ⇒ 발주 추가 검토` 형태로 간결하게 정리 + 복사
- **⏰ 입고 지연 확인 보고서**: 확정은 됐지만 입고예정일이 지나도록 들어오지 않은 물량만 모아, 물류센터·거래처 확인이 필요한 건을 별도 보고서로 확인 + 복사
- **행 클릭 → PO 상세 내역**: SKU별로 묶인 발주번호·물류센터·확정여부·입고여부를 개별 라인으로 확인

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 대시보드 본체 (`coupang_doc_dashboard_v3.html`을 그대로 배포) |
| `deploy_coupang_1p_doc.py` | 로컬에서 대시보드 HTML을 수정한 뒤, 이 스크립트를 실행하면 GitHub 저장소에 자동 커밋 + Pages 재배포 |

## 대시보드 갱신 방법

로컬의 `coupang_doc_dashboard_v3.html`을 수정한 뒤 아래 스크립트를 실행하면 자동으로 재배포됩니다.

```bash
python deploy_coupang_1p_doc.py
```

GitHub 인증 토큰은 코드에 포함되어 있지 않으며, 로컬의 `github_config_coupang1pdoc.json`
또는 환경변수 `GITHUB_TOKEN`에서 읽습니다(이 파일은 저장소에 올라가지 않습니다).
